ICE TASK 1 & 2 : Project proposal and Planning 

> Goals & Objectives 
The primary goal of this project is to build a responsive , multi-page web platform for the Osizweni Science Centre in Secunda, Mpumalanga. The platform aims to increase community engagement, promote STEM educationprograms, and enables local Schools to submit online excursion  bookings.

> Current analysis 
Existing community access to STEM program details and schools visist bookings is primarily offline. This website provides a centralized, accssible 5-page  responsive website where schools can view offerings  and submit booking requests online.

>Proposed features and functionality 
- 5-Page navigation: home (`index.html`), About Us (`about.html`), Programmes (`programmes.html),Booking (`booking.html`), and Contact Us (`contact.html`).
- Sematic HTML5: build using `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- Interactive forms : Clients-side validation for excursion bookings and general inquiries.
- Responsive Layout: CSS Grid for program display and flexbox for mobile navigation for mobile navigation.

>Design Aesthetic and Wireframe 
- Color Palette: Navy Blue (`#003366`), Light Blue (`#e6f2ff`), Charcoal (`#333333`).
- Sitemap Flow : `Home`  `About Us`  `Programmes`  `Bookings`  `Contact Us`
